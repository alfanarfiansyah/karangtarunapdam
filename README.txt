# KARANG TARUNA KPR PDAM KLAWUYUK

Website profil Karang Taruna KPR PDAM Klawuyuk, Kota Sorong, Papua Barat Daya.

## Struktur
- index.html
- css/style.css
- js/main.js
- images/logo.jpg

## Fitur
- Navbar gelembung/floating
- Menu mobile yang bisa dibuka/tutup
- Active menu saat scroll
- Hero
- Tentang Kami
- Visi & Misi
- Program Kerja
- Kegiatan
- Struktur Pengurus
- Uang Kas tanpa database
- Agenda
- Galeri + lightbox
- Aspirasi WhatsApp
- Kontak & Footer

## Uang Kas
Tidak menggunakan database. Data pemasukan/pengeluaran disimpan di localStorage browser.
Artinya data hanya tersimpan pada browser/perangkat tempat website digunakan.

Untuk website online dengan data kas yang bisa diakses banyak pengurus, nanti perlu database + backend PHP/MySQL.

## Yang perlu diganti
1. Nama pengurus pada section Pengurus.
2. Nomor WhatsApp pada bagian Aspirasi.
3. Email resmi.
4. Foto kegiatan pada folder images.
5. Agenda dan program sesuai kegiatan sebenarnya.
